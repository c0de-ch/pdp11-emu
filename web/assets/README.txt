PDP-11/70 web UI assets (embedded into pdp11d, see embed.go)

js/        ES modules, no build step: main.js (entry), ws.js (protocol client),
           console.js (xterm.js console), prefs.js, util.js,
           panel/ (front panel: svg.js art, lamps.js, controls.js, input.js, panel.js),
           ui/ (toolbar, dialogs, system chooser, help, tutorial, layout, ...)
css/       app.css (shell), panel.css (front panel), console.css (terminal)
panel/     geometry.json: panel geometry in millimetres, generated by
           web/dev/gen-geometry.mjs from docs/research/r4-assets/panel1170_elements.json
fonts/     woff2 fonts built by web/dev/build-fonts.py, with their licences:
             glass-tty-vt220.woff2   Glass TTY VT220, Viacheslav Slavinsky (Unlicense)
             vt323.woff2             VT323, Peter Hull (SIL OFL 1.1), subset
             archivo-panel*.woff2    Archivo, Omnibus-Type (SIL OFL 1.1), instanced
                                     at wdth 85 / wght 600 and 500, subset
           The bezel tagline and "digital" letters are outlines of Montserrat
           Alternates (SIL OFL 1.1) converted to SVG paths (geometry.json "art").
vendor/    xterm/: @xterm/xterm 6.0.0 (MIT), lib/xterm.mjs and css/xterm.css
           unchanged from the npm package, LICENSE.txt
img/       favicon.svg
